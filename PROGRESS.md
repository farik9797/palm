## Статус
Статический макет 3D-карты Бухары для сайта недвижимости (Palm) собран в `site/`. Ждём от клиента реальные объекты.

## Сделано (20.11.2026)
- `site/index.html`, `styles.css`, `app.js`, `tokens.css`, `base.css`.
- Первый экран: улицы прорисовываются от центра к окраинам → проявляется карта → камера наклоняется, здания поднимаются в 3D → падают метки.
- Метки двух видов: объекты (круг) и ориентиры (ромб). Наведение/фокус открывает карточку, клик закрепляет её.
- Список под картой = источник данных меток (`#rows li[data-pin]`, координаты в `data-lng`/`data-lat`, фото — `data-photo`). Фильтр «Всё / Объекты / Ориентиры», поиск в шапке.
- Проверено headless-Chromium: интро, карточки, поиск, переход к метке, 1280 и 390 px, ошибок в консоли нет. sloplint: 0 FAIL.

## Ключевые решения (и почему)
- MapLibre GL 4.7.1 + тайлы OpenFreeMap (данные OSM): реальная карта, без ключей и оплаты.
- Линии для прорисовки берутся из тайлов в браузере (`querySourceFeatures`) — отдельный файл с улицами не нужен.
- GSAP не подключён: вся анимация внутри MapLibre и CSS.
- Дизайн: Hallmark, тема Furrow (тёплая бумага, терракота). Шрифты заменены на Onest / Golos Text / JetBrains Mono — у Red Hat нет кириллицы.
- Высоты зданий — из OSM; в Бухаре они почти везде не указаны, поэтому дома низкие (5 м по умолчанию).
